# Missing Ranges

## Problem

Given a sorted and unique integer array `nums` and an inclusive range `[lower, upper]`, find all the numbers that are missing from the range.

Return the missing numbers as a list of ranges.

Each range should contain the starting and ending missing number.

## Example 1

**Input:**

```text
nums = [0,1,3,50,75]
lower = 0
upper = 99
