# Remove Element

## Problem

Given an integer array `nums` and an integer `val`, remove all occurrences of `val` from `nums` in-place.

The order of the elements may be changed.

Return the number of elements in `nums` that are not equal to `val`.

Let this number be `k`.

The first `k` elements of `nums` must contain all elements that are not equal to `val`.

The elements beyond the first `k` positions are not important.

### Example 1

**Input:**

```text
nums = [3,2,2,3]
val = 3
